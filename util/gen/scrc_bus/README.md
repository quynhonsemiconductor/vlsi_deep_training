# `util/gen/scrc_bus` — SCRC internal APB BUS

Generated by APB-BUS-Generator from `scrc_apb_bus.xlsx`; `gen.sh` is the recipe
(`make gen IP=scrc_bus`, checked by `make gen-check`). QNSC_SCRC_MAS 3 and 7.4.

The workbook (edit it, then regenerate):

| Sheet | Content |
|---|---|
| CFG | Module Name `m_qnsc_scrc_apb_bus`; Data Width 32; Write Strobe 4; PSLVERR on Unmapped Access 1 |
| CFG, masters | `MCPU` 14 bit (MRV-CPU BIU `o_paddr[13:0]`); `IBEX` 14 bit (P_BUS `APB_M0`, contract `meta.apb_paddr_width`) |
| CFG, slaves | `SCRC_CSR` 5 bit (`m_qnsc_scrc_csr`, offsets 0x00..0x1C) |
| MM-CFG | `SCRC_CSR` at `0x0` for both masters |
| MM-INFO | `SCRC_CSR` `0x0000 - 0x001F` for both masters |

Offsets 0x0020..0x3FFF hit no slave: the generated decoder answers `PSLVERR`.
The module names are renamed from the generator's `m_vlsi_*` (see `gen.sh`) so this
bus and P_BUS, made by the same tool, can be compiled into one chip.
