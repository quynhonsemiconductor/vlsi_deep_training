# `bus` — bus fabric: S_BUS crossbar, P_BUS router, AXI2APB

**Owner:** @SinhHPT   **Spec:** [`doc/specs/QNSC_BUS_MAS.md`](../../doc/specs/QNSC_BUS_MAS.md) (build to
`.docx` via `doc/build/build_docs.py`)   **DV:** [`../../dv/bus`](../../dv/bus)

## What this block is

The chip's two buses and the bridge between them. `S_BUS` is a fully-connected
AXI4 crossbar (`axi_xbar`): three masters issue transactions here (SYSDBG on
`AXI_S0`, CPU on `AXI_S1`, DMA on `AXI_S2`) and four destinations answer them
(ROM `AXI_M0`, ISRAM `AXI_M1`, DSRAM `AXI_M2`, the `AXI2APB` bridge `AXI_M3`).
`AXI2APB` (`axi_to_axi_lite` + `axi_lite_to_apb`) converts the `AXI_M3` traffic
to APB4 and hands it to `P_BUS`, which fans it out to fourteen peripheral
slaves. `bus` is an **integration** block (design/README.md, "Shared numbers:
who may use `qnsc_pkg`"): it imports the contract package directly, since
sizing the crossbar's own address map is exactly the chip-level job an
integration block exists to do.

**This PR delivers `S_BUS` and the `AXI2APB` bridge, ending at a flat APB4
port.** `P_BUS`'s own router (`m_vlsi_apb_router`, generated by
`nguyenquanicd/APB-BUS-Generator` from the current 14-peripheral contract) is
the next step, not yet wired in here -- see `doc/specs/QNSC_BUS_DECISIONS.md`.

## The wrapper is the boundary

`rtl/` holds **only code written here**. Upstream IP is listed in
[`bus.f`](./bus.f), never copied into `rtl/`. Reading this one directory answers
what is ours and what is borrowed.

The block's outward boundary is `rtl/m_qnsc_wrap_bus.sv`, hand-written (not
Emacs AUTOINST-generated: `axi_xbar`'s ports are arrayed structs, not the flat
per-signal style AUTOINST decomposes, so there is nothing for the tool to
derive here). No packed structs cross this module's own ports, per the naming
rule -- every AXI channel is flattened field by field, matching
`design/cpu/rtl/emacs/m_qnsc_wrap_cpu_cpu2axi.sv`'s own convention.

`m_qnsc_wrap_bus`'s own top-level ports:

| Port | Direction | Note |
|---|---|---|
| `i_clk_cpu`, `i_rst_n_cpu` | in | shared with `cpu`/`sysdbg` (qnsc_pkg's "cpu" clock cluster: hardwired on, never gated) |
| `i_axi_s_0_*` | in | AXI4 from SYSDBG (`AXI_S0`) |
| `i_axi_s_1_*` | in | AXI4 from CPU's CPU2AXI bridge (`AXI_S1`) |
| `i_axi_s_2_*` | in | AXI4 from DMA (`AXI_S2`) |
| `o_axi_m_0_*` | out | AXI4 to ROM (`AXI_M0`) |
| `o_axi_m_1_*` | out | AXI4 to ISRAM, covers both the debug window and the application region (`AXI_M1`) |
| `o_axi_m_2_*` | out | AXI4 to DSRAM (`AXI_M2`) |
| `o_apb_*` / `i_apb_*` | out/in | flat APB4 master port, `AXI2APB`'s output -- P_BUS's own single master-input port (`APB_S0`) |
