# `uart` — serial ports

**Owner:** @Vinh-OngBao   **Spec:** [`QNSC_UART_MAS.md`](../../doc/specs/QNSC_UART_MAS.md)   **DV:** [`../../dv/uart`](../../dv/uart)

## What this block is

Two 16550A-compatible serial ports on `APB_M8` and `APB_M9`. `UART0` carries the
boot download. Upstream `apb_uart` wrapped by `m_qnsc_wrap_uart`. `o_dma_rx_req` is the RX request of `dma_axi32`; TX uses `o_int_uart`.

## The wrapper is the boundary

`rtl/` holds **only code written here**. Upstream IP is listed in
[`uart.f`](./uart.f), never copied into `rtl/`. Reading this one directory answers
what is ours and what is borrowed.

## DMA request (patched vendor)

`o_dma_rx_req` = `reg_q.LSR.data_ready` of `obi_uart`: a level, 1 while RX data is unread, falling 2 clock
after the last RHR read (1 clock with the FIFOs off). It reaches the wrapper through one added output on
each of `obi_uart`, `apb_uart_wrap` and `apb_uart` (`DMA_RX_REQ`), two patches in
[`vendor/patches/`](../../vendor/patches/). Nothing existing changes. `dma_axi32` needs `PERIPH_DELAY >= 1`
on the RX channel. TX has no pin (`LSR.thr_empty` stays 1 after the first THR write): the DMA TX request
is `o_int_uart`, with IER enabling the one TX source.

The wrapper adds no logic apart from that wiring: `PADDR[2:0]` = `i_bus_apb_paddr[4:2]`, `PSTRB`/`PPROT`
not used, modem inputs tied 1, modem outputs open (MAS 5, 10).

## Instances

Two, `UART0` and `UART1`, identical; they differ only in their connections.
